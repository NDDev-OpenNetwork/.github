# Contributing

Thank you for contributing to NDDev Open Network.

## Before you start

1. Search existing issues and pull requests.
2. Open an issue for changes that alter public APIs, security boundaries,
   governance, licensing, or architecture.
3. Read the repository's `README.md`, `AGENTS.md`, and local contribution guide.

## Development workflow

1. Fork the repository or create a short-lived branch when you have write access.
2. Keep each pull request focused on one outcome.
3. Add or update tests and documentation with the implementation.
4. Run the repository's documented checks locally.
5. Open a pull request describing motivation, behavior change, validation,
   security impact, and rollback.
6. Resolve review feedback without rewriting unrelated work.

Use conventional commit subjects when practical, for example
`feat(parser): accept streamed input` or `fix(ci): pin upload action`.

## Contributions made with agents

Agent assistance is welcome. The pull request author remains accountable for
the result and must disclose material agent-generated changes. Never provide an
agent with production secrets, personal data, or broader credentials than the
task requires. Generated changes receive the same tests and review as human
authored changes.

## Licensing

By submitting a contribution, you agree that it is licensed under the license
of the target repository and that you have the right to submit it.
