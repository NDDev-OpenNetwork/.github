# Governance

NDDev Open Network uses maintainer-led, review-driven governance.

- Maintainers define repository scope, review changes, publish releases, and
  enforce community and security policy.
- Contributors influence direction through issues, discussions, design notes,
  and pull requests.
- Significant changes should record alternatives, security impact, migration,
  and rollback before implementation.
- Protected branches change through reviewed pull requests with passing checks.
- Maintainer or agent privileges are granted narrowly and reviewed regularly.

Routine technical decisions use lazy consensus. Changes to governance,
licensing, security boundaries, repository visibility, or destructive provider
state require explicit owner approval.
